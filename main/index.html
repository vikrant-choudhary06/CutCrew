Installing the apps

The apps are downloaded straight from CutCrew, so your device asks for permission once.

Android: install the APK
  1. Tap Download APK above and open the file when it finishes.
  2. If Android asks, allow Install unknown apps for your browser or file manager.
  3. Tap Install, then open CutCrew from your app drawer.
Android TV: install the APK
  1. On your TV, open Settings and allow Install unknown apps for your file manager.
  2. Copy cutcrew.apk to the TV with a USB drive or an app like Send Files to TV, or download it on the TV's browser.
  3. Open the file to install. CutCrew then appears under Apps on your TV's home screen.
Windows: run the installer
  1. Run cutcrew-windows-setup.exe once it has downloaded.
  2. If Windows shows Windows protected your PC, choose More info then Run anyway.
  3. CutCrew installs in a few seconds and appears in the Start menu.
